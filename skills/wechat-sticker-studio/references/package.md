# 投稿目录与校验

2026-11-06 核对的微信公开指南允许专辑包含 8～24 张之间任意数量的表情，整套统一动态或静态。本 Skill 交付动态专辑。投稿当天以官网和实际表单为准。脚本采用十进制字节预算，原图和预览放在投稿目录之外。[微信表情制作规范](https://sticker.weixin.qq.com/cgi-bin/mmemoticon-bin/readtemplate?t=guide/index.html#/makingSpecifications#specifications_stickers)

| 投稿文件 | 用途和默认校验 |
|---|---|
| `表情/01.gif` 至 `表情/NN.gif` | 240×240，无限循环，有不同画面与正帧时长，各 ≤500,000 字节 |
| `封面.png` | 240×240，透明背景，≤500,000 字节；建议正面半身或全身 |
| `聊天面板图标.png` | 50×50，透明背景，≤100,000 字节；优先头像 |
| `详情页横幅.jpg` 或同名 PNG | 750×400，≤500,000 字节；本流程使用无文字、有色实底 |
| `专辑文案.txt` | UTF-8；名称不超过 8 个汉字，本工具要求填写 1～80 字介绍，每张一个不超过 4 字的含义词 |

**文案示例。** 文件头和两个示例行如下。每行用全角空格、制表符或至少两个半角空格分隔三列；编号必须覆盖全部 GIF。无字图在文案的台词列记为「无字」。图上台词与含义词可以不同。

```text
专辑名称　工牌虾
专辑介绍　工牌比脸大，嘴比壳还硬。

编号　图上台词　含义词
01　收到　确认
02　我来　接手
```

**在用户机器上生成清单**，例如投稿目录名为 `投稿`，`SKILL_DIR` 指向 Skill 所在目录：

```sh
uv run --script "$SKILL_DIR/scripts/album.py" 投稿 \
  --manifest 工作/upload-plan.json --zip 导出/微信表情包.zip
```

脚本逐帧解码，校验编号、图像、文案和无限循环，再输出 ZIP 与 UTF-8 JSON。仅需检查时省略两个输出选项。ZIP 只收录投稿素材；用于填表的 JSON 含本机绝对路径、SHA-256 和逐图含义词，仅保留在本机。浏览器读取 `title`、`intro`、`stickers[].{id,file,caption,meaning}`、`cover.file`、`banner.file` 和 `icon.file`。退出码非零时先修复，修复后重跑；浏览器仅使用本轮成功生成的清单。若手里只有 ZIP，先检查条目，解压到独立工作目录，再对解压结果运行校验。
