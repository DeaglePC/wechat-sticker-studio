# 从一句群聊回复画到 GIF

**默认的 16 张**可以先排 8 张日常回复、4 张该群特有的场景、4 张招牌反应。比例可调。相同台词若动作和语气也相同，合并。每张分镜写「上一句 → 回话意图 → 图上台词或无字 → 动作的起、承、落 → 普通话含义词」。自拟对话标为自拟。

| 同事刚说 | 我想表达 | 图上台词 / 含义词 | 三个姿势 |
|---|---|---|---|
| 文件发你啦，按这版走 | 接到了，会照做 | 收到 / 确认 | 看到消息 → 敬礼 → 蓝工牌甩到下巴 |
| 我还在路上，会议快开始了 | 我先帮你顶住 | 我顶着 / 救场 | 转头 → 抓住工牌 → 举牌当盾 |
| 今天先到这儿吧 | 先走，明天见 | 撤啦 / 下班 | 蹲下蓄力 → 冲出去 → 回头挥手 |

**锁定角色。** 先确定脸型、主色、线宽、衣服和一个缩小仍能看见的特点。留好透明母版，下一张显式传入母版。真人授权不明确时不要擅自把真实照片用作公开形象。用户要虚构面孔时，直接生成，并记录 AI 使用范围以备投稿。用角色自己的道具演情绪，例如工牌既能敬礼时打到自己，也能举起来给同事挡事。

**可直接改写的关键帧提示词**

> 参考附图中的同一个角色，保持脸、服装、轮廓、配色一致。画一张宽横向、真透明背景的动画原画条带，一行三格，三个角色各自在格内居中，头顶、四肢和道具完整，格间留足透明间距。三格之间保持机位和人物大小。由左到右演出「看到消息」「抬手敬礼」「大工牌翘起来碰下巴」。眼神与手势随动作改变，图上无字、无格线、无水印。

**合成。** 三格条带可以直接用下列命令。`--lean` 和 `--hold-ms` 按动作调整。快跑等大位移优先另做足够的姿势或序列帧；若角色闪跳，先对齐身体锚点再编码。若源图格间粘连，重画或分开三格再合成。图标和封面从无字幕母版中取清晰头像与半身形象，横幅单独画一个和角色有关的故事。

```sh
uv run --script "$SKILL_DIR/scripts/animate.py" salute-keys.png 投稿/表情/01.gif \
  --caption 收到 --font /path/to/authorized-chinese-font.otf \
  --lean -3 --hold-ms 350 --frames-dir 制作/帧/01
```

`SKILL_DIR` 是本机这个 Skill 的目录。有台词时传入能覆盖这些汉字且有相应授权的字体。无字时省略 `--caption` 和 `--font`。帧目录选用新路径。为封面、图标和横幅分别导出符合平台尺寸的文件。[投稿目录与校验](package.md)

**手机大小验收。** 每张缩到 120 像素，在深浅两种背景各播两个周期。看字幕是否清楚、手指数量是否合理、道具有没有变形或裁切。让不看台词的人描述动作；整套若重复扭动同一张图，就回到分镜重画。选取最能表达动作的一帧做带编号的总览，优先让用户看到可播放的 GIF。

选题案例中，叔婆饭把带娃日常画成家长能用的邀约，「小蓝和他的朋友」用肢体语言把角色的性格演出来。可借鉴选场景和设计动作的方法，另做原创形象。[创作者访谈](https://www.sohu.com/a/115396011_465296) · [案例报道](https://www.xinhuanet.com/tech/20230828/c781319b72754030abb0924057101fa7/c.html)
